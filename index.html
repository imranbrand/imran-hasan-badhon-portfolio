Deep learning research

Image Caption Generator

A CNN-LSTM model that looks at a picture and writes a sentence about it.

Role
Researcher and developer: data preparation, model design, training, tuning and evaluation.
Status
Completed research project, supervised by Dr Selina Sharmin. Presented at the academic pre-defense with positive feedback from faculty and peers.

Overview

My M.Sc. research project at Jagannath University. Xception extracts high-level visual features from each image, and an LSTM network learns to turn those features into grammatical captions. It is trained on the Flickr8k dataset of 8,000 images with five captions each.

  • Python
  • TensorFlow
  • Keras
  • CNN
  • LSTM
  • NumPy

How it works

  1. ImageFlickr8k
  2. XceptionCNN features
  3. LSTMsequence model
  4. Captiongenerated text

Features and decisions

Data

Flickr8k: 8,000 images with five captions each. Text is tokenised and padded, and images are turned into feature vectors.

Encoder

The Xception CNN extracts high-level visual features from every input image.

Decoder

An LSTM reads the image feature plus the words so far and predicts the next word.

Training

Hyperparameter tuning and dropout regularisation, which improved the BLEU scores.

Inference

Captions are generated word by word, and the model produced relevant captions for unseen images.
